# Flutry dokumentáció

Ez a saját használatra készített dokumentációs projekt a Flutry keretrendszerhez.

## A projektről

A Flutry egy TypeScript-alapú backend keretrendszer Node.js-hez. A projekt főbb területei az útválasztás, a middleware-ek, az adatbázis-integráció, a CLI-eszközök és a moduláris csomagok.

## Technológiák

- React Router v7
- TypeScript
- MDX

## Fejlesztés

```bash
yarn install
yarn dev
```

A helyi dokumentációs oldal a fejlesztői szerver által kiírt címen érhető el.
https://flutry.otamoon.hu

## Megjegyzés

Ez egy személyes, belső projekt. A dokumentáció a Flutry aktuális API-ját és használatát követi.
