Flutry applications run on Node.js and TypeScript. The simplest path is the official CLI, which downloads the starter template and optionally installs dependencies.

## Create a project with the CLI

Install or run the CLI with your preferred package manager, then start the interactive generator:

```bash
npx @flutry/cli new
```

The generator asks for a folder name, package name, database settings, Socket.IO preference, package manager, and whether dependencies should be installed immediately. It supports npm, Yarn, and pnpm.

<details>
<summary>Manual package installation</summary>

For an existing TypeScript project, install only the packages you need:

```bash
npm install @flutry/server @flutry/common
npm install @flutry/database-sequlize
npm install @flutry/redis
```

`@flutry/database-sequlize` uses Sequelize plus the `mariadb` and `mysql2` drivers. `@flutry/redis` uses ioredis.

</details>

## Build and run

The starter projects use TypeScript and expose the following scripts:

```bash
yarn dev
yarn build
yarn start
```

Use the package manager selected during project creation for equivalent commands.

> **Important**
>
> The server loads routes before it starts listening. A missing or invalid route module therefore fails startup rather than silently producing an incomplete application.
